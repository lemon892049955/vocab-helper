# 英语单词学习插件 · 需求方案

## 1. 背景与目标
在日常浏览英文文档、网页时，用户经常遇到不会的词或句子。本插件要抓住这个场景，把「遇到 → 查词 → 翻译 → 收藏」的链路缩短到一次操作，并把内容沉淀成个人生词本，便于后续复习。

### 产品目标
- 划词即得翻译，**只在用户主动选择时调用 AI**，降低打扰和成本。
- 一键保存，并自动带上上下文，而不是只存一个孤零零的翻译。
- 提供本地优先的生词本，支持检索、标签、导出。
- 翻译由 DeepSeek 驱动，接口可替换、结果可缓存。

### 非目标（MVP 不做）
- 不做整页沉浸式翻译。
- 不做多端云同步、用户账号体系。
- 不做词组自动切分 / 整句自动朗读等进阶功能。
- 不上架 Chrome 商店（第一版本地加载即可）。

## 2. 目标用户与核心场景
### 2.1 目标用户
需要阅读英文文档、论文、技术博客、外文新闻，并希望积累词汇的中文用户。

### 2.2 核心场景
1. **阅读时遇到生词**：选中英文单词 → 立即显示音标 / 词性 / 中文释义 / 例句 → 点击收藏。
2. **遇到整句看不懂**：选中句子 → 显示整句翻译和重点词汇 → 一键收藏。
3. **回头复习**：打开插件面板，按时间、标签、分类筛选，标记「认识 / 模糊 / 忘记」。
4. **导出到其他工具**：导出 CSV / JSON，后续可导入 Anki 等。

## 3. 功能范围
### 3.1 MVP（P0）
- 划词识别：监听鼠标划选，区分「单词」「短语」「句子」。
- 悬浮翻译卡：在选中文字附近弹出，展示翻译结果，提供「收藏」按钮。
- 一键收藏：保存原文、翻译、上下文句、来源网址、页面标题、时间。
- 生词本：Popup 中列表展示、搜索、按类型 / 标签过滤、删除。
- 设置：填写 DeepSeek API Key、选择模型、设置目标语言。
- 翻译缓存：相同原文 + 相同语言方向命中缓存，不发请求。
- 导出：CSV / JSON 导出。

### 3.2 第二阶段（P1）
- 标签、文件夹、批量管理。
- 简单间隔重复：`认识 / 模糊 / 忘记` 三键复习。
- 收藏时支持手动补充释义、例句。
- 设置页允许切换 provider（OpenAI 兼容），不只 DeepSeek。
- 导入 Anki / CSV 导入。

### 3.3 远期（P2）
- 云同步与多设备。
- 词频标色、难词预标注。
- 基于上下文截图 / OCR 识别（PDF、图片）。
- 与 LLM 结合生成个性化例句、词根词缀解释。
- 每日复习提醒、学习统计。

## 4. 功能详述
### 4.1 划词识别
- 在 `mouseup` 时获取浏览器 Selection。
- 对选中文本归一化：去首尾空白、压缩连续空白。
- 长度判定：
  - 1 个英文词 → `word`
  - 2~5 个词 → `phrase`
  - 更多词或含完整句子标点 → `sentence`
- 有选中文本时显示悬浮按钮 / 直接弹卡；点击页面空白处关闭。

### 4.2 翻译卡片
- 展示状态：加载中 → 成功 / 失败 / 需要配置。
- 字段：
  - 单词：音标、词性、中文释义、英文例句 + 中文例句翻译。
  - 句子：整句中文翻译、重点词汇表。
- 操作：复制、收藏、重新翻译、关闭。
- 未配置 Key 时引导到设置页，而不是报裸错误。

### 4.3 收藏笔记
- 存储完整上下文：原文、翻译、上下文句（前后文）、来源 URL、页面标题、标签、语言方向、创建时间、更新时间。
- 同一条原文可更新而非重复创建。
- 收藏成功给予轻提示。

### 4.4 生词本
- 列表倒序展示，支持搜索原文 / 翻译 / 标签。
- 筛选：全部 / 单词 / 短语 / 句子 / 已复习 / 未复习。
- 操作：查看详情、编辑释义、添加标签、删除、导出。

### 4.5 设置
- DeepSeek 配置字段：
  - API Key（本地保存，星号显示）
  - Base URL（默认 `https://api.deepseek.com`）
  - 模型（默认 `deepseek-chat`）
  - 源语言 / 目标语言（默认 auto → 中文）
- 提供「测试连接」按钮。
- 成本相关选项：是否启用缓存、缓存过期策略（默认永久，可手动清除）。

### 4.6 导出
- CSV 字段：类型、原文、翻译、音标、词性、例句、标签、来源 URL、创建时间。
- JSON：完整原始数据，便于备份或后续导入。
- 文件命名带日期，如 `vocabulary_20261004.json`。

## 5. 数据模型（概念层）
```
Note {
  id: string
  type: "word" | "phrase" | "sentence"
  original: string
  translation: string
  phonetic?: string
  partOfSpeech?: string
  exampleOriginal?: string
  exampleTranslation?: string
  contextSentence?: string
  sourceUrl?: string
  sourceTitle?: string
  tags: string[]
  targetLanguage: string
  review: {
    status: "new" | "learning" | "known"
    reps: number
    lastReviewedAt?: number
    dueAt?: number
  }
  createdAt: number
  updatedAt: number
  model: string
}
```

## 6. 非功能需求
- **隐私**：API Key 只存本机 Chrome 存储；除非明确选择同步，数据不上传第三方服务器。
- **性能**：悬浮卡出现时间 < 300ms（不含网络），翻译结果优先走缓存。
- **成本**：相同文本不重复调用；请求只包含翻译所需上下文。
- **安全**：Key 不写入日志、不写入代码仓库；网络请求集中在 background，出错有兜底提示。
- **兼容**：目标 Chrome 114+，Manifest V3。
- **稳定性**：页面样式被注入时使用 Shadow DOM，避免与目标站点 CSS 冲突。

## 7. 验收标准
- 在英文网页选中单词，能出现悬浮卡并获得中文释义。
- 点击收藏后，Popup 中能立即看到该条记录及来源网址。
- 同一单词再次选中时命中缓存，不发第二次请求。
- 未配置 Key 时，点击翻译给出明确配置引导。
- 数据可成功导出为 CSV 和 JSON。
- 插件在任意可选中文本的页面上不破坏原页面样式和交互。

## 8. 里程碑
1. **M1 项目骨架**：MV3 工程 + Content Script + Popup 可运行。
2. **M2 翻译闭环**：DeepSeek 接入、翻译卡、缓存、错误处理。
3. **M3 记录闭环**：收藏、生词本、搜索 / 删除 / 编辑。
4. **M4 实用闭环**：设置、导出、基础测试与打磨。
